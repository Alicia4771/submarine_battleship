# submarine_battleship

TGS2026に向けて開発している、  
**実物の潜望鏡型コントローラとUnityを連動させた潜水艦探索・通信ゲーム**です。

プレイヤーは潜水艦の乗員となり、ソナーと潜望鏡を使って海上の艦船を探索します。

敵艦を発見したら、敵艦が発する光信号を記憶し、
潜望鏡を格納してから信号を入力・送信します。

---

## ゲームコンセプト

このゲームのコンセプトは、

> **「潜望鏡でしか得られない情報を、自分で探し・覚え・伝える」**

です。

ソナーでは艦船のおおよその位置しか分からず、
敵・味方・中立の判別はできません。

そのため、プレイヤー自身が潜望鏡を海上へ出し、
実際に潜望鏡を回しながら艦船を探す必要があります。

ただし、潜望鏡や通信マストを長時間海上へ出していると、
敵に発見される危険があります。

**「情報を得るために海上を見るか、安全のために潜るか」**
を判断しながら、高得点を目指します。

---

## ゲームの流れ

1. ソナーを使用して周囲の艦船のおおよその位置を確認
2. 潜望鏡を海上へ上げる
3. 潜望鏡を回転させて艦船を探す
4. 敵艦を発見し、光信号を記憶
5. 潜望鏡を水中へ格納
6. 記憶した信号を物理ボタンで入力
7. 通信マストから信号を送信
8. 信号の正誤判定
9. 制限時間内にできるだけ高いスコアを目指す

---

## ゲームモード

### 通常信号モード

敵艦が発する信号の
**「短い・長い」**
を記憶するモードです。

信号入力時はボタンを押している時間によって、

- 短く押す：`・`
- 長く押す：`―`

として入力します。

### 色記憶モード

敵艦が発する

**赤・青・黄**

の光る順番を記憶するモードです。

潜望鏡を格納したあと、
記憶した順番どおりに色ボタンを押して信号を送信します。

---

## 操作方法

| 操作 | 内容 |
|---|---|
| 潜望鏡を左右に回す | ゲーム内の潜望鏡を左右に回転 |
| 黒ボタン / Button1 | ソナー |
| 赤ボタン / Button2 | 潜望鏡上昇 / 色記憶モードでは赤を入力 |
| 青ボタン / Button3 | 潜望鏡下降 / 色記憶モードでは青を入力 |
| 黄ボタン / Button4 | 通常信号入力 / 色記憶モードでは黄を入力 |

信号入力中は入力モードを切り替え、
潜望鏡操作と信号入力が競合しないように制御しています。

---

## スコア

現在のゲームでは、
プレイヤーの行動と通信結果によってスコアが変化します。

| 条件 | スコア |
|---|---:|
| 潜望鏡・通信マストを格納 | +3 / 秒 |
| 潜望鏡を海上へ出している | +12 / 秒 |
| 通信マスト送信中 | +3 / 秒 |
| 通信成功 | +600 |
| 通信失敗 | -200 |
| 敵に発見される | -400 |

制限時間は **90秒** です。

潜望鏡を海上へ出すことで多くの時間得点を獲得できますが、
長時間出し続けると敵に発見される危険があります。

---

## 危険度システム

潜望鏡や通信マストを海上へ出している間、
危険度が上昇します。

危険度が一定値に達すると敵に発見され、
スコアが減少します。

潜望鏡や通信マストを格納すると、
一定時間後から危険度が回復します。

この仕組みにより、

**「もう少し観察するか、それとも敵に見つかる前に潜るか」**

という判断が必要になります。

---

## ハードウェア

ゲーム専用の潜望鏡型コントローラを製作し、
Unityと連携させています。

主な構成は以下の通りです。

- Raspberry Pi 4B
- BNO055 9軸センサ
- 物理ボタン
- 回転入力用センサ
- USBシリアル通信
- 潜望鏡型筐体

センサから取得した潜望鏡の向きやボタン入力を
Raspberry PiからUnityへ送信し、
ゲーム内の操作へ反映しています。
